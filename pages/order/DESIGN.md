# 点菜页 `pages/order`

继承 [`docs/DESIGN-MASTER.md`](../../docs/DESIGN-MASTER.md)

## 职责

按日期/餐次查看点菜清单、未读通知、删单、分享、跳转选菜。

## 布局

- 渐变日期条 + 分享按钮
- 未读通知卡片（有数据时）
- `.segment-bar` 早餐/午餐/晚餐
- 点菜项：渐变边框 + 缩略图 + 备注 + 点菜人

## 组件要点

- 日期文字 `--color-primary` 加粗
- 删除 `×` 触控区 ≥ 44pt
- float-btn：渐变环 + 白底橙 +（与 `.gradient-border` 卡片同系），`.page-with-fab` 留白
