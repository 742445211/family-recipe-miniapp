# AI 推荐 `pages/ai-recommend`

继承 [`docs/DESIGN-MASTER.md`](../../docs/DESIGN-MASTER.md)

## 调性

活泼幽默、信息只说一遍：Hero 里交代 5 道菜与数据来源，别处不再重复数字。

## 配额规则

- **每 3 小时最多 3 次**（非「今日」）
- 无 `rate_limit` 时展示规则提示；有数据时展示剩余次数

## 布局

```
Hero（kicker + 标题 + 一句说明 + 天气一行 + 配额一行 + 按钮）
→ 加载骨架 | 结果列表「好了，上菜！」 | 空状态
```

## 文案

| 场景 | 文案 |
|------|------|
